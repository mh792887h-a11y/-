# 🏛️ صندوق الأحوال المدنية (Civil Status Fund)

نظام إلكتروني لإدارة صندوق ومبيعات استمارات الأحوال المدنية والسجل المدني، مخصص لأمين الصندوق ومدير الإدارة.

**برمجة وتصميم: محمد هشام الصلاحي**

---

## 📱 المميزات الرئيسية
- 📋 **تسجيل بيع الاستمارات فورياً**: (جديد، تجديد، بدل فاقد، بدل تالف) مع تحديد الجنس (ذكر / أنثى).
- 💰 **الاحتساب الآلي للحصص**: تفصيل فوري لكل عملية (حق الدولة، حصة الإدارة، نصيب الصندوق).
- 🧾 **إصدار وطباعة إيصالات رسمية**: دعم الطباعة المباشرة وحفظ الإيصال بصيغة PDF.
- ⚖️ **إدارة الصندوق ومطابقة الجرد**: مقارنة الرصيد الدفتري بالرصيد الفعلي وإظهار المطابقة أو العجز أو الزيادة.
- 📊 **اليوميات والإغلاق المحاسبي**: إغلاق اليومية وتأمينها، وإعادة فتحها بصلاحيات الإدارة.
- 📑 **سجل الديون والمصروفات الإضافية**: متابعة الديون وسدادها، وتقييد الخرج والدخل المتنوع.
- 🛡️ **سجل مراجعة وتدقيق كامل (Audit Trail)**.
- 💾 **نسخ احتياطي واستعادة قاعدة البيانات** محلياً بدون إنترنت.

---

## 🛠️ البناء والتطوير عبر GitHub و Android Studio

### المتطلبات الأساسية
- **JDK 17**
- **Android Studio Ladybug (2024.2+)** أو أحدث
- **Android SDK Platform 36**

### أوامر البناء بواسطة Gradle Wrapper:
```bash
# إعطاء صلاحية التنفيذ للـ wrapper (في لينكس وماك)
chmod +x gradlew

# بناء نسخة الـ Debug
./gradlew assembleDebug

# ملف الـ APK الناتج:
# app/build/outputs/apk/debug/app-debug.apk
```

## ⚙️ البناء الآلي (GitHub Actions CI/CD)
المشروع مزود بملف سير عمل جاهز داخل:
`.github/workflows/android-build.yml`
يقوم بالبناء التلقائي واستخراج ملف الـ APK وتوفيره للتحميل المباشر كـ Artifact مع كل عملية Push أو Pull Request أو تشغيل يدوي (Workflow Dispatch).
